## 社交预览图(Social Preview)

建议在仓库 Settings → General → Social preview 上传一张 1280×640 的封面图,
包含:t66y-automatic 字样、"自动签到 · 自动回帖 · 新帖监控" 三个卖点、Node.js 标识。
有封面图的仓库在分享链接和 GitHub 探索页中的点击率显著更高。

## 其他 SEO 要点

1. **README 首段**已按关键词密度优化,Google 通常抓取前 150 字符作为摘要,请勿改动首段结构。
2. **Release 标题**使用 `v1.0.0 - 草榴社区 t66y 自动签到回帖工具` 这类带关键词的格式。
3. 在知乎、V2EX、Reddit(r/China_irl 等技术向板块)分享时,链接自带描述与封面图,转化更高。
